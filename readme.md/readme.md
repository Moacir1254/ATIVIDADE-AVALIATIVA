
# ⚽ FutGestão
## Sistema de Gestão de Escolinhas de Futebol

### 📌 Tema do projeto
Desenvolvimento de um sistema web para gestão de escolinhas de futebol.

### 📝 Descrição do projeto
O FutGestão é uma aplicação web desenvolvida com o objetivo de facilitar a administração de escolinhas de futebol. O sistema busca centralizar informações e tornar mais simples a organização de alunos, treinadores, turmas, horários e mensalidades.

### 🎯 Objetivo geral
Desenvolver um sistema web para auxiliar na gestão de escolinhas de futebol, oferecendo uma ferramenta simples e organizada para administrar suas atividades.

### 📍 Objetivos específicos
- Permitir o cadastro e gerenciamento de alunos.
- Possibilitar o cadastro de treinadores.
- Organizar turmas e horários de treinamento.
- Auxiliar no controle de mensalidades.
- Centralizar as informações em um único sistema.
- Facilitar o acesso e a organização dos dados da escolinha.
