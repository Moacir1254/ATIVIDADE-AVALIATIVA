# ⚽ FutGestão

**Sistema web para gestão de escolinhas de futebol.**

## 📌 Sobre o projeto

O FutGestão é uma aplicação web desenvolvida com o objetivo de facilitar a administração de escolinhas de futebol, centralizando informações e auxiliando na organização das atividades.

## 🎯 Objetivo

Desenvolver um sistema que permita gerenciar alunos, treinadores, turmas, horários e mensalidades de maneira simples e organizada.

## 🚀 Tecnologias utilizadas

- Vue.js
- JavaScript
- HTML5
- CSS3
- Git e GitHub

## ⚙️ Funcionalidades planejadas

- Cadastro de alunos
- Cadastro de treinadores
- Gerenciamento de turmas
- Organização de horários
- Controle de mensalidades
